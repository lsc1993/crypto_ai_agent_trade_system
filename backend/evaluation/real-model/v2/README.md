# 综合研究事实引用评估 v2

沿用父目录四案和公开历史K线，新增 `numeric_facts`。三个历史案例各包含64条由生产 `historical_candle_facts` 从结构化 Candle 生成的窗口/逐根OHLCV事实；稀疏案例为空，不能补造数值。

模型只返回独占行事实token，生产适配器检查其证据绑定并渲染完整语句。安全报告额外绑定渲染模块指纹；v1输入、首次付费结果与旧哈希保留。用法仍见[父目录说明](../README.md)，默认入口已指向本目录。

每条语句保留字段标签、单位、观察时间及统计范围。它解决原子事实字段/值绑定，不能证明相邻自然语言、推断因果、所有中文绕写或长期抗注入能力。具名人工评分仍须独立执行，缺失输出保持未评分。
