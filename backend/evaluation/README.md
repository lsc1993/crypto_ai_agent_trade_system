# 综合研究离线契约评估集 v1

在 `backend/` 执行 `python -m scripts.evaluate_research`，可用 `--output PATH` 归档安全 JSON。
使用已安装项目依赖的 Python；不需要模型配置、数据库、外网或真实账户。

`suite.json` 声明案例与预期；`request*.json` 是合成的冻结公开证据；`response*.json`
是固定 HTTP 响应。评估器通过 `MockTransport` 调用真实 `DeepSeekResearchLanguageModel`，
复用格式、长度、交易文本、证据引用和有限重试校验。数据独立于 `tests/`，不导入测试私有 helper。
修改样本时审查响应和预期并更新集合版本；输出还包含整组数据、实际 Prompt 和 Pydantic 契约指纹。

案例覆盖合法双周期报告、坏 JSON、伪造证据、交易措辞、未授权数值字段、新闻边界伪造、
缺少模型配置和超时。接受、拒绝、降级分别统计，每案分类、错误码和调用次数都必须匹配；
空集、损坏文件、越界路径、预期不匹配和产物写入失败均非零退出，不输出原始响应或异常。

本集评估确定性适配器行为，不是真实模型质量或收益基准。固定合法响应无法测量真实模型的
抗注入能力，新闻案例只核对实际请求边界及转义。数值案例只证明模型不能新增仓位字段，
不证明任意正文数值真实。降级统计表示适配器产生可降级的配置/上游错误，不代表已经运行
研究图的证据不足门控或完成降级持久化；这些仍由现有研究服务测试覆盖。

第二阶段的[独立流程评估](flows/README.md)补充实际综合研究及技术 v2 服务路径，原有适配器集的覆盖边界不变。完整入口会分别运行并归档两套版本指纹，真实 SQL 历史读取由单独数据库回归证明。
