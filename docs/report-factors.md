# AI 报告专题分析

新生成的 Agent 报告在原有中文双周期报告中增加三个专题，展示确定性事实、行情影响、短期与长期传导条件、失效条件和冻结证据链接。

| 专题 | 数据范围 | 分析口径 |
| --- | --- | --- |
| 美国政策 | SEC、CFTC、美联储、美国财政部现有官方 RSS，研究开始前 7 天 | 相关宏观与监管事件优先入选，显示机构、发布时间、摘要；区分政策宣布与生效 |
| 资金费率 | Binance USD-M 中已准入且有该数据能力的研究币种，近 7 天已结算历史 | 最新值、样本平均与累计、正负零次数、末尾已获取样本连续同号数及时间覆盖 |
| 美国现货 ETF | Farside 的美国 BTC／ETH 现货产品汇总表，动态识别基金列 | 最新披露日、各基金贡献、最近 5 个完整披露日累计及已验证的连续资金方向，金额统一为美元 |

每个专题独立显示“数据可用／部分覆盖／缺少数据／采集失败”。单一来源失败不会阻止其他专题与原报告生成。没有通过校验的模型解释时保留事实并说明限制；整体模型输出降级时也可查看已冻结的专题事实。

动态研究币种不意味着所有专题都有数据。ETF 适配器仅支持 BTC/ETH；其他币种不得套用 BTC/ETH 数据作为该币种的 ETF 流量。研究币种管理页的初始同步能力状态不代表报告专题已完成采集。

## 时间、披露和证据

- 政策仅纳入截止时间内的相关事件。RSS 数量及证据配额有限，采集成功不代表一周政策完整；没有取得事件也不等于没有政策。
- 资金费率是已结算费率，不是下一期预测。样本缺口或不规则间隔会标记部分覆盖；样本连续同号不能证明缺失时段的真实结算连续性。正负费率不能直接等同涨跌。
- ETF 交易日期按纽约日期解释，抓取时间使用 UTC。纽约当日数值暂定，即使全部基金已显示数字，也不计入此前五个完整披露日累计与连续方向统计。当前部分披露行仍会显示。
- ETF 空白、短横线和未披露值保持缺失；零流量与负流量分别显示。休市不补零。工作日空档可能来自休市或缺失数据，连续性采用保守口径。
- Farside 页面可能后续修订。此适配器仅支持实时研究请求，允许研究启动到采集开始不超过 5 分钟的延迟；拒绝历史回填与未来请求。证据保存实际抓取完成时间、原始值和哈希，交易日不伪装为精确发布时间。
- 模型解释只能引用对应专题的冻结证据。影响判断包含条件和不确定性，不把政策、费率或资金流直接作为价格因果证据。

## 升级与兼容

新增迁移 `0014_report_factors`，在 `agent_report_details` 增加可空 JSONB 字段 `factor_analysis`。无需新增生产依赖或 API Key。原有报告保持原样，空字段兼容读取；专题内容仅在升级后新生成的报告中保存。

部署新版后端之前，对目标环境执行项目现有的前向迁移流程。在 `backend` 目录运行：

```powershell
uv run alembic upgrade head
```

项目 Docker API 启动脚本已经在启动前运行此命令，使用既有 Compose 更新流程即可。此迁移不回写历史报告，降级删除审计字段被禁止。前端须同步更新以展示专题。
