# 研究币种同步恢复设计

## 目标与边界

补齐失败初始同步的手动恢复；保留每次任务、逐来源状态和操作审计，不自动重放失败任务、不扩大交易范围。复用现有 PostgreSQL 表及租约，不增加生产依赖，不修改业务环境。

## 方案选择

仅增加重试按钮无法解决卡死任务；自动无限重试会扩大公开源流量且掩盖故障。因此本批选择有界 worker 加显式手动重试，保持单 worker 装配。

## 契约

- `POST /research-symbols/{symbol}/sync/retry`，请求 `{runId: UUID}`，返回 202 和 `SyncRun`。
- 只能重试启用目录中已失败的任务。锁目录行后检查所属标的和版本；活跃重试复用同一任务，无活跃任务时只有最新失败 ID 可以排队。新任务结束后迟到的旧请求返回 409，不再排队；未知标的/任务 404，归档和不适用状态 409。
- worker 默认整任务 120 秒、心跳 10 秒，租约仍为 30 秒；参数仅供代码装配/测试，不增加环境开关。失去租约或续租异常立即取消采集，不写运行终态；由租约过期回收终结。协程取消尽力保存安全的中断失败后继续传播取消。
- 每次 claim 先回收过期 running 为 failed/sync_lease_expired，不自动重放；renew/finish 在截止时刻即失效。终态仍不可变，旧 token 不能改写状态、来源或快照关联。
- 采集服务可能在失去租约前已独立提交不可变行情快照；本批不改变其事务边界，不保证撤销快照。任务关联与研究准入以有效租约提交为准。
- 页面失败项提供“重试同步”，排队/运行时不可重复操作，轮询目录到终态；保留已有成功历史授予的研究资格，单独展示最新失败。
- HTTP、Mock、Hybrid 适配器同步维护；Mock 明确使用离线状态，不请求公开源。

## 验收

单元测试覆盖超时、续租、失租、取消和异常；SQL 测试覆盖崩溃后回收、并发重试、迟到请求、归档、旧所有者与审计。API 与前端测试覆盖请求契约、错误和状态刷新。运行统一 full 与浏览器检查，明确未验证的外部源和部署范围。
