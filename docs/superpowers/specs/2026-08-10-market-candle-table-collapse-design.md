# 市场页底部折叠 K 线文本数据设计

## 目标

不再在 K 线图下方完整展示 OHLC 表格。将当前周期的 K 线文本数据移动到市场页最底部，并默认折叠；用户可按需展开核对完整数据。

## 已确认的需求

- K 线图区域仅展示交互式红绿 K 线与图注。
- OHLC 文本表格置于市场资讯之后，作为市场页最后一个内容区。
- 文本数据区默认折叠，不主动渲染为可见的大表格。
- 展开标题和表格始终对应当前选中的周期。
- 不改变行情接口、领域模型、公开市场研究边界或 K 线图本身。

## 方案

使用原生 HTML `<details>` 和 `<summary>`，默认不添加 `open` 属性。浏览器提供键盘操作、展开状态和无障碍语义，无需新增 React 状态或第三方折叠组件。

将表格从 `MarketChart` 提取为独立的 `MarketCandleDataTable` 组件：

1. `MarketChart` 只负责 Canvas K 线图、图注与空数据提示。
2. `MarketCandleDataTable` 只接收 `CandleSeries`，并沿用当前开盘时间、开高低收、成交量与收盘时间的格式化表格。
3. `MarketPage` 在 `NewsTimeline` 后渲染 `<details className="market-candle-data">`。它的 `summary` 形如“查看 1h K 线文本数据”，内部放置表格。
4. 当前周期没有数据时，页面不渲染该折叠区，原有图表空状态保持不变。

## 样式与可访问性

- 折叠区沿用研究面板的深色卡片风格，标题可点击并显示明确的展开提示。
- 表格仅在 `details[open]` 状态下占据页面空间；横向滚动样式保持不变。
- `summary` 是可键盘操作的原生控件；表格继续保留 `caption`，用于数据语义和屏幕阅读器。
- 文本数据区位于市场资讯之后，保证图表、衍生品与资讯优先显示。

## 测试与验收

- 页面测试验证：默认不存在 `open` 属性、表格位于折叠区内、点击标题后 `details.open` 为真。
- 验证周期切换后 summary 与表格 caption 更新为新周期。
- 验证无 K 线数据时只有原空态，不出现空折叠区。
- 运行市场页与图表测试、前端 lint、类型检查、完整测试和生产构建。
- 重建 Docker Compose，实际检查表格位于页面底部、默认关闭、展开后内容可读且切换周期同步。
