# Skill 技术研究报告设计

## 目标与已确认范围

保留综合研究报告，新增独立技术分析功能区。假设当前空仓，允许条件化做多/做空研究计划，包含入场区间、结构止损、目标与盈亏比，不涉及实际账户、金额、仓位和杠杆，不生成 TradeIntent，不连接风控或执行服务。用户已确认按推荐范围实施。

## 方法包

采用量价分析、区间突破、多周期确认，反转形态按证据选择性启用。将用户提供的 runtime Skill 审查改编为项目内静态版本化方法包；记录原 Skill ID、原文 SHA256、改编说明、方法文本哈希。删除操纵市场视角、确定性盈利或内幕参与推断；不执行 Skill 指令、脚本或动态工具。原始文件保持不变。

一期不支持 VAP、周/月线周期阶段、账户持仓管理、事件交易、通用 Skill 上传管理。方法包是分析方法而非市场证据。

## 数据与计算

只读取现有公开行情适配器，日线背景、4h 结构、1h 触发。至少每周期 60 根连续已收盘 K 线，统一截止时刻、币种一致，拒绝重复/断档/过期数据。成交量基准为信号之前 20 根的均值；相对量达到 1.5 为放量，低于 0.7 为缩量。实体/振幅不超过 0.3 为小实体，长影线至少为实体两倍。阈值属于项目规则 v1，未宣称为书中原值或已优化参数。

确定性代码计算量价特征、SMA20/50 背景、已确认枢轴、ATR14 和信号。枢轴使用右侧确认 K 线且不能越过截止时刻；模型不得改写这些事实。候选计划只顺日线与4h共同趋势；以1h收盘突破先前20根区间并有量能确认为触发条件，未触发可输出等待确认的条件计划。三周期方向冲突、数据不足、无结构目标或盈亏比不足时无计划并说明原因。

入场区间、止损与目标由结构及 ATR 缓冲计算；使用区间最不利入场价计算盈亏比。目标必须由冻结支撑阻力支持，禁止为了凑盈亏比凭空设置。入场已远离区间则不追价。计划有效期为截止后4小时，展示待触发/已失效含义。手续费每侧0.05%、滑点每侧0.05%仅为明示研究假设，计算成本调整盈亏比，门槛1.5；不模拟成交和部分成交，不宣称与回测/模拟盘等价。

## 报告与模型边界

独立 report DTO，包括版本、ID、run ID、币种、UTC生成/截止时间、completed/degraded、方法版本、数据质量、量价事实、计划数组、无计划原因、模型叙事和安全错误码。API 使用 camelCase，金融字段为十进制字符串。

模型使用现有 DeepSeek 配置、无工具 JSON 调用；输入限本次冻结技术事实与已批准方法。模型只提供定性主判断、反向情景与风险说明，引用当前证据 ID；不允许模型生成价格、仓位、杠杆、胜率和收益承诺。输出严格 schema、有界文本、当前证据引用校验；失败时保存降级报告，保留确定性事实与计划并明确标记 AI 不可用。不足以计算时不调用模型、不产生计划。

## 独立流程、审计与持久化

在 agent/technical/ 放固定流程与方法；reports/technical.py 定义新契约，api/routes/technical_reports.py 暴露独立接口。通过 Harness 新增 technical_research 类型与专用策略，只授予公开行情、模型格式化及不可变报告保存能力。无新闻依赖、无执行能力。

新增 technical_reports 表保存报告与内部冻结证据；证据包含本次实际使用的K线、计算参数、方法指纹及载荷哈希，API仅返回安全事实摘要，不回传原始K线载荷。报告保存与 Harness 终态同事务。新增0017前向迁移及不可变触发器，扩展Harness类型/策略约束，不改写旧表数据和旧报告校验。

接口：POST /api/v1/technical-reports {symbol} 返回完整报告；GET 同路径按symbol/page/pageSize分页；GET /{id} 读取历史。重新生成调用POST形成新ID；归档币种可读历史不可新建。

## 交互

综合研究页面增加技术分析入口，新页面 /technical-reports 独立选择币种、手动生成、分页历史；/technical-reports/:reportId 展示报告。按钮加载防重复；切换币种后旧请求不能跳转或显示为新币种结果；URL非法、空目录、归档、失败、缺数据与模型降级均有明确状态。

WorkbenchApi 新增 startTechnicalReport/listTechnicalReports/getTechnicalReport，HTTP/Hybrid连接新接口，Mock明确标识模拟数据。旧报告入口、接口、规则不变。

## 验收

先写失败测试，再实现。覆盖无未来泄漏、量价阈值、趋势冲突、最不利入场及费用滑点、缺失/重复/断档/过期、伪造引用与模型越界、降级、Harness准入、不可变持久化和事务一致性、旧报告回归、前端切换与迟到请求、Mock/HTTP/Hybrid契约。运行后端Ruff/Pyright/pytest，前端lint/typecheck/test/build，数据库仅使用已确认的专用测试库；不可用如实报告。代码测试不代替真实模型质量和策略盈利验证。
