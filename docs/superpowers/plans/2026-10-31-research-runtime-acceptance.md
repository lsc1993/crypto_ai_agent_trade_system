# 研究报告 HTTP 闭环与任务恢复验收

## 目标与边界

延续现有 HTTP 验收和固定研究语料，以真实路由、worker、Harness、SQL 仓储验证手动技术研究从提交、后台执行、保存、历史读取到降级展示。选择技术 v2 队列作为研究闭环，避免为同步综合研究另造后台能力。行情与模型仅使用审查过的合成输入及固定 HTTP 响应；页面仍走真实后端，不使用浏览器请求拦截。

任务恢复采用现有语义：未保存的过期运行标记 interrupted，不自动重放；已保存报告优先恢复终态。取消指 worker 停机/任务协程取消，当前无用户取消 HTTP 接口，不在本轮新增。用真实专用数据库、可控 UTC 时钟和事件同步复现重启、租约到期、提交后取消、重复提交及旧所有者迟到保存，避免真实长时间等待或人为修改业务数据库。

保持之前未提交改动，不提交、推送、部署、使用真实模型或修改 .env；不增加依赖或 schema。独立临时库由受限角色操作，所有随机 schema 由现有准入和生命周期管理。
