# 综合研究事实一致性修复方案

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement the approved plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 防止综合研究模型把证据中的收盘、开盘、局部低点或成交量时段错配后通过校验，同时保持交易隔离。

**Architecture:** 用户已选择方案A，保留正文数值并引入结构化事实引用与程序渲染。原实现只绑定证据UUID，没有绑定数值的字段、单位和时间范围。数值出现在证据中并不足以证明叙述正确，不能用数字白名单或更强Prompt冒充语义校验。

**Tech Stack:** 现有 Python/Pydantic/Decimal/pytest；不新增生产依赖或业务数据库字段。

## 方案A：保留正文数值，结构化事实引用与确定性渲染（推荐）

2026-11-02 用户明确选择本方案。实施落点：新增 `agent/numeric_facts.py` 提供Decimal/UTC事实、白名单快照/专题投影、结构化历史K线统计和原子语句渲染；`model.py` 在压缩前校验、渲染后复用原契约；`prompt.py` 提供目录和独占行协议；`service.py` 连接冻结载荷；评估新增独立v2，v1不覆盖。持久化继续保存既有字符串和证据引用，无数据库/前端契约变更。

当前目录覆盖快照价格/涨跌幅/成交额/持仓/费率、已准入公开上下文、单一来源的政策计数及资金费率标量；历史评估使用逐根OHLCV及窗口开盘/收盘/高低值。真实观测与统计截止分开；没有完整类型化交易日期绑定的ETF暂不生成正文token，确定性专题区仍展示原数值。没有可安全绑定的事实不提供数值token，现有确定性结构区照常展示支撑阻力。文本或复合专题值不猜测为标量。

模型只能选择冻结的事实标识，不直接生成数值。程序从可信的结构化采集结果建立事实目录，每条事实绑定证据ID、字段、单位、观察时段及确定性展示语句；不能从模型或新闻自由文本猜测这些绑定。目录缺失的事实不得补造。

模型输出中的事实引用经过准入和对应证据检查后，由程序渲染完整的带标签事实语句。禁止引用之外的自由数值陈述；拒绝未知标识、错误证据绑定与不支持的数量表达。不能把任意数字占位符插入自由标签，从而再次形成“开盘=收盘值”的错误。历史已保存报告保持原样。

实施顺序：结构化事实与精度/UTC测试 → 模型引用和禁止自由数值的失败测试 → 确定性渲染/长度/引用校验 → 综合服务与固定评估样本接线 → 文档、完整回归与明确额度下的单独付费复测。必要时先核对前端展示与持久化兼容性，不擅自新增schema。

验收必须覆盖：开盘/收盘互换、局部/窗口最低值互换、成交量时段错配、跨证据借值、未知事实、无事实目录、Decimal与单位、稀疏证据、合法引用成功。此方案只能保证绑定事实语句，不能宣称自然语言因果解释已被完全证明。

本批实现了原子语句渲染、压缩前拒绝自由数值、快照/专题接线和独立v2输入。两份旧付费错误提案离线回放均拒绝；v2真实复测已执行但未通过可用性验收（1接受/2拒绝/1额度阻塞）。后续补充显式诊断回调，修复全局缓存日志器导致诊断丢失的问题；拒绝原文不保存，旧报告不回填。该回调只接收有界错误字段，模型不能选择或执行它。
