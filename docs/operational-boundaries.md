# 运行边界

2026-11-02 按用户要求从活动新闻来源移除 CFTC 与美国财政部 RSS；后续请求不再访问两源，政策覆盖以 SEC、美联储为分母。历史报告、证据与已存新闻保留原来源归因，不做删除或回写。

综合市场研究报告由用户手动点击“抓取公开行情与英文新闻并分析”触发，输出短期（数天至两周）与长期（数周至数月）市场观点。公开行情查询、币种准入检查及初始同步也会读取公开数据，不能把所有网络读取都理解为报告按钮触发。技术研究使用下述独立规则；两类报告均不定时生成或自动交易。

研究范围由研究币种目录管理：除预置 BTCUSDT 与 ETHUSDT 外，可登记通过检查的 Binance USDT 永续合约。新增币种后初始同步任务入队，API lifespan 中的单 worker 消费队列，空闲时等待；它不是模型工具，也不自动生成报告或执行交易。失败同步支持携带失败任务 ID 的手动重试，重复请求复用活跃任务，迟到的旧请求不会再排队；默认整任务超时 120 秒，每 10 秒续租，过期运行回收为失败，不自动重试。归档币种不能重试。研究币种扩展不改变交易、回测和模拟盘的静态契约。

新闻仅使用已登记的全球英文 RSS/官方公告元数据：SEC Press Releases、Federal Reserve Press Releases、CoinDesk、Decrypt、Blockworks、The Block。每次手动运行只读取 feed 中的标题与摘要；单一来源不可用会在报告中体现为覆盖不足。系统不使用社交平台、通用网页爬虫、新闻全文镜像、付费聚合 API 或浏览器自动化；新闻标题和摘要都按不可信证据处理，不能改变 Agent 的固定执行路径。

新闻条目在原有校验规则下逐条处理：缺少元数据、非法时间/链接或英文文本校验拒绝只过滤对应条目，并保存本次安全计数；合法条目继续参与窗口和币种筛选。网络、响应大小、压缩及安全 XML 解析错误仍使整个来源失败。报告通过冻结的来源覆盖与限制说明区分读取失败、条目过滤、空订阅、保留条目窗口无内容和预算截取；这些情况均不能冒充完整覆盖。保留条目的窗口统计先于币种筛选，不将币种无相关新闻误写为来源没有近期内容，也不推断预算截去条目的时效。旧报告不回写，研究证据不足的门控保持有效。

公开市场上下文使用 Binance USDⓈ-M 的只读公开端点和 Alternative.me 的恐惧与贪婪指数；BTC/ETH 美国现货 ETF 专题还可读取固定 Farside 公开表。该适配器只解析已批准页面，不提供通用爬取能力。每次报告保留来源归因；任一来源不可用时，不会用历史值冒充新数据，而是明确标注缺失或失败。报告证据在本次运行冻结，前端只读取安全摘要、确定性专题事实与元数据，不接收原始证据 payload 或经 URL 传递原始详情。

初始同步主要采集行情、K 线、衍生品与资金费率；新闻和情绪留待报告运行。管理侧 ETF 能力状态与报告侧 BTC/ETH ETF 专题是不同路径。专题日期、披露完整性及历史回填限制见[专题说明](report-factors.md)。归档币种保留历史报告，不能据此为归档币种发起新的研究。

DeepSeek 仅作为受限 JSON 研究格式化器：每次请求只能接收本次冻结的公开行情、新闻及专题证据或审查后的技术方法，不能调用工具、网页、数据库、文件或交易所接口。其输出必须经确定性代码验证，并只能引用当前报告的不可变证据 ID。原有综合报告继续使用中文双周期叙事，不构成买卖、开平仓、仓位、杠杆、止损或收益承诺。报告用于研究和复核，属于非投资或交易指令，不承诺收益。

综合正文保留数值，但通过独立 `fact_refs` 数组引用冻结结构化事实目录，绑定目标段落自身证据后由程序渲染完整字段、单位与UTC范围；模型不得自由改写具体数值。未绑定或错误引用的候选在压缩前拒绝，有限纠错耗尽后降级；未请求的专题也不能自行新增。当前门禁不证明所有自然语言语义，不能据此宣称报告质量已通过。既有报告不回写，确定性结构和专题数据区保持原数值与日期口径。

公开上下文的合并参考时刻不是逐个指标的真实观测时点；正文事实语句会明确这一限制。事实的字段、数值、单位和时段在压缩中作为整体处理，不能仅留下部分元数据。

独立的 [Skill 技术研究报告](technical-reports.md) 由用户手动触发，只读取已准入研究币种的公开行情，不依赖新闻。确定性代码可计算假设空仓的条件化入场区间、结构止损、目标及成本调整盈亏比；模型仅提供定性解释，不能改写价格或生成金额、仓位和杠杆。技术研究不生成 TradeIntent，不访问账户、风控放行或执行服务，不持续监控计划；历史报告的触发状态是冻结状态，到期不自动重算。

市场研究 Harness 是固定、手动且受策略约束的协调层，仅限已批准的公开输入及可选的无工具模型格式化调用；它没有任意工具路由、长期用户记忆、私有账户访问、模拟订单调用或真实执行能力。

交易能力仅限于本地、确定性风控校验后的模拟盘。真实下单不支持：不接入真实账户或私有 API，也不执行下单、撤单、资金划转或提现。

系统不承诺收益、表现或任何交易结果。所有本地操作均应保持可审计，并遵循仓位、杠杆、止损、最大亏损、冷却期和熔断等确定性风控约束。

技术报告 v2 见 [交易计划书](technical-trading-plan.md)。用户手动提交后由专用固定 worker 执行思考分析与非思考编排；模型只选择程序验证的研究候选并引用冻结事实，数字由程序渲染。队列不自动监控或定时生成，不输出 TradeIntent，不访问账户、风控放行或执行服务；原始思考不保存或展示。
