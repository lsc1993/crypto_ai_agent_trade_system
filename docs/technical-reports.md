# Skill 技术研究报告

技术研究与原有综合研究使用独立页面、接口和存储。综合研究继续提供新闻、专题及双周期观点；技术研究侧重量价、区间和多周期结构，条件满足时展示假设当前空仓的多头或空头研究计划。

## 使用与状态

从报告页进入“技术分析”，或访问 `/technical-reports`。选择已就绪的研究币种后手动生成报告；每次生成保存新报告，历史不可改写。归档币种仍可查看历史，但不能生成新报告。`/technical-reports/:reportId` 可直接打开历史详情。

`api` 和 `market-api` 模式调用本地后端及 PostgreSQL，`mock` 使用明确标注的演示数据。技术研究沿用已有 DeepSeek 配置；缺少密钥、超时或模型内容不合规则保存降级报告，保留可计算的事实和计划。数据质量不足时不调用模型，也不生成计划。“报告完成”不等于存在可用计划，“计划已触发”仅表示冻结收盘证据满足条件，不代表成交。

## 计算口径

仅使用现有公开行情适配器，要求日线、四小时、一小时各至少六十根连续、及时的已收盘 K 线。指标计算使用最近六十根；冻结证据保留参与质量校验的全部闭合序列及摘要，支持复核早期断档或重复。未收盘数据不参与信号、枢轴或均线。

- 三周期 SMA20/50 方向一致才允许候选计划。支撑阻力来自有右侧收盘确认的局部枢轴。
- 一小时信号之前二十根构成区间与均量基准，相对量至少 `1.5` 为放量，低于 `0.7` 为缩量。小实体比例不超过 `0.3`，长影线至少为实体两倍。
- 放量收盘越过区间才标记为已触发，且本次最新价格须仍在入场带；未突破且收盘价与最新价均位于未突破一侧、距离边界不超过半个 ATR14，可给出等待确认计划。远离入场带、方向冲突、缺少结构止损或目标时不输出计划。
- ATR14 的四分之一作为入场带及结构止损缓冲。目标使用最近的对应结构阻力或支撑，不为满足盈亏比凭空延长。
- 每侧手续费 `0.05%`、每侧滑点 `0.05%` 是研究假设。以最不利入场价计算，收益扣除入场与目标退出成本，风险加入入场与止损退出成本；净收益风险比至少 `1.5`。
- 计划在数据截止后四小时到期。历史报告保持生成时状态，页面另行提示到期；不会监控后续价格或自动更新触发状态。

以上阈值是项目规则，未经参数优化或盈利验证。价格全程使用 Decimal，公开接口最多十八位小数、共三十八位数字；不能安全表达价格或会破坏止损/目标顺序时不产生计划。计划不包含金额、仓位、杠杆或真实账户信息，也不生成 `TradeIntent`。本功能没有成交模拟或部分成交模型，不能将其结果等同于回测、模拟盘或真实成交。

模型只解释确定性事实，输出中文主判断、反向情景与风险，并引用本报告证据 ID。模型不能生成计划价格、修改数值或调用任何工具；原有综合报告校验不变。

## API、存储与升级

| 请求 | 行为 |
| --- | --- |
| `POST /api/v1/technical-reports`，JSON `{ "symbol": "BTCUSDT" }` | 手动生成并返回完整报告，HTTP 201 |
| `GET /api/v1/technical-reports?symbol=BTCUSDT&page=1&pageSize=20` | 分页历史，symbol 可省略，pageSize 最大 100 |
| `GET /api/v1/technical-reports/{id}` | 读取报告，缺失返回 404 |

响应为 camelCase，金融值为十进制字符串。原始冻结 K 线和完整方法正文仅保存在后端，API 返回安全摘要与方法指纹。独立的 `technical_research` Harness 策略只授权公开行情、受限模型与报告保存。

前向迁移 `0017_technical_reports` 新增 `technical_reports` 表，扩展 Harness 类型/策略约束，并增加不可变触发器；报告与 Harness 终态审计同事务提交。它不修改历史综合报告。升级需按[本地部署指南](local-deployment.md)在目标环境执行既有迁移流程；本次开发仅在独立测试数据库验证，未迁移正在使用的业务库。
